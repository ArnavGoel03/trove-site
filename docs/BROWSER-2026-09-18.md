## Defect closed during verification

The download page independently selected the first non-Windows release, so a
newer Relay or Tend release could become Trove's Mac download. The page now uses
one canonical release fetch and app/platform/channel/asset selector shared with
client tags and app release resolution. Mac uses stable Trove; Windows retains
its prerelease channel. Drafts, malformed tags and missing matching assets are
excluded. Existing built-in published tags remain the outage fallback.

The mixed-app regression drives the actual page and was calibrated against the
previous page source, which fails it. Repository-wide tag-selection searches
found no remaining copy of the first-non-Windows shortcut. Generated release
metadata remains identical to upstream main.
